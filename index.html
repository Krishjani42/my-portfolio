College Scheduler - 3 Fold Canvas

A responsive web application for managing college schedules with a unique 3-fold canvas design

View Project

Left Fold: Navigation & Filters

Left side ek powerful sidebar hai jahan se poore College Scheduler ko control kiya ja sakta hai. Yahan se user (jaise faculty ya admin) easily different views aur filters apply kar sakta hai.

  • Profile / Logo: App logo aur logged-in user details (e.g., Faculty Name).
  • Smart Filters: Branch / Course (e.g., Computer Science), Semester / Division, Faculty ke basis par timetable filter.
  • Navigation Links: Dashboard Home (Canvas), Manage Subjects/Courses, Manage Faculties, Reports / Analytics.
  • Quick Stats: Total classes today, active rooms, quick overview without opening reports.

Middle Fold: Main Timetable Canvas

Ye central workspace hai jahan actual timetable banta aur dikhai deta hai. Drag-and-drop based modern grid jise dekhte hi poora schedule samajh aata hai.

  • Date / Week Selector: Top header se week ya particular date par jump kar sakte hain.
  • Timetable Grid: Rows as time slots (9:00 AM, 10:00 AM, ...) aur columns as days (Monday–Saturday).
  • Interactive Class Cards: Har cell me class card (Subject, Room, Faculty) jo move/resize ho sakta hai.
  • Drag & Drop: Class ko easily ek time slot se dusre slot me shift karne ki capability.
  • Add New Class: Canvas ke andar floating / fixed “Add New Class” button se naya lecture schedule karna.

Right Fold: Details & Quick Actions

Right side ek dynamic inspector panel hai jo context ke hisaab se change hota hai. Yahan detailed information, quick forms aur conflict alerts dikhte hain.

  • Contextual View: Agar koi class select nahi hai to “Upcoming Classes for Today” ya general notifications dikhte hain (jaise “Lab 1 is double booked!”).
  • Class Details: Class card par click karne par Branch, Division, Room, Notes, duration, etc. ke saath full detail view.
  • Quick Actions: Selected class ke liye Edit, Delete, Reschedule jaise direct buttons.
  • Quick Add Form: Chhota form jisse bina page change kiye naya class schedule kiya ja sakta hai.
  • Conflict Alerts: Agar same faculty ya room ek hi time me 2 jagah assign ho jaye to red alert boxes ke through highlight.
