# ⚡ Quick Fill Guide - Portfolio Information

## 🎯 `index.html` File में Direct Fill करने वाली जगहें:

---

### 📌 **Line 6** - Page Title
```html
<title>Your Name - Portfolio</title>
```
➡️ अपना नाम लिखें

---

### 📌 **Line 17** - Navigation
```html
<div class="nav-brand">Your Name</div>
```
➡️ अपना नाम लिखें

---

### 📌 **Line 44** - Hero Name
```html
Hi, I'm <span class="highlight">Your Name</span>
```
➡️ अपना नाम लिखें

---

### 📌 **Line 46** - Profession
```html
<p class="hero-subtitle">Your Profession/Role</p>
```
➡️ जैसे: `Web Developer`, `Software Engineer`

---

### 📌 **Line 47-49** - Description
```html
<p class="hero-description">
    A brief description about yourself...
</p>
```
➡️ 2-3 lines में अपने बारे में लिखें

---

### 📌 **Lines 55-58** - Social Links
```html
<a href="#" target="_blank">LinkedIn</a>
<a href="#" target="_blank">GitHub</a>
<a href="#" target="_blank">Twitter</a>
<a href="#" target="_blank">Email</a>
```
➡️ `#` की जगह अपने URLs लिखें
- LinkedIn: `https://linkedin.com/in/yourprofile`
- GitHub: `https://github.com/yourusername`
- Email: `mailto:your.email@gmail.com`

---

### 📌 **Lines 75-83** - About Bio
```html
<p>Write a compelling paragraph...</p>
<p>Add another paragraph...</p>
```
➡️ 2 paragraphs में detailed bio लिखें

---

### 📌 **Lines 86, 90, 94** - Statistics
```html
<h3>50+</h3> <p>Projects Completed</p>
<h3>3+</h3> <p>Years Experience</p>
<h3>20+</h3> <p>Happy Clients</p>
```
➡️ अपने actual numbers लिखें

---

### 📌 **Lines 112-150** - Skills
```html
<span data-percent="90%">JavaScript</span>
<div class="skill-progress" style="width: 90%"></div>
```
➡️ अपनी skills और percentages update करें
- Skill name change करें
- दोनों जगह same percentage

---

### 📌 **Lines 170-220** - Projects (3 projects)
```html
<h3>Project Name 1</h3>
<p>Brief description...</p>
<span>React</span> <span>Node.js</span>
<a href="#">Live Demo</a>
<a href="#">Code</a>
```
➡️ हर project के लिए:
- Name
- Description
- Technologies
- Live demo link (अगर है)
- GitHub link

---

### 📌 **Lines 233-264** - Experience
```html
<div class="timeline-date">2023 - Present</div>
<h3>Job Title</h3>
<h4>Company Name</h4>
<p>Description...</p>
<li>Achievement 1</li>
```
➡️ हर experience के लिए:
- Date range
- Job title
- Company name
- Description
- Key points (bullet list)

---

### 📌 **Line 281** - Email
```html
<p>your.email@example.com</p>
```
➡️ अपना email लिखें

---

### 📌 **Line 288** - Phone
```html
<p>+91 1234567890</p>
```
➡️ अपना phone number लिखें

---

### 📌 **Line 295** - Location
```html
<p>Your City, Country</p>
```
➡️ जैसे: `Mumbai, India`

---

### 📌 **Line 322** - Footer
```html
<p>&copy; 2024 Your Name. All rights reserved.</p>
```
➡️ अपना नाम लिखें

---

### 📌 **Lines 324-326** - Footer Links
```html
<a href="#" target="_blank">LinkedIn</a>
<a href="#" target="_blank">GitHub</a>
<a href="#" target="_blank">Twitter</a>
```
➡️ Same URLs जो hero section में हैं

---

## 🖼️ **Optional: Photo Add करें (Line 62)**

अगर photo add करना है:
```html
<div class="hero-image">
    <img src="your-photo.jpg" alt="Your Name" 
         style="width: 320px; height: 320px; border-radius: 50%; object-fit: cover;">
</div>
```

---

## ✅ **Quick Checklist:**

1. ✅ Name (3 जगह: title, nav, hero)
2. ✅ Profession/Role
3. ✅ Description
4. ✅ Social media links (4)
5. ✅ About bio
6. ✅ Statistics (3 numbers)
7. ✅ Skills (6 skills + percentages)
8. ✅ Projects (3 projects)
9. ✅ Experience (3 items)
10. ✅ Contact (email, phone, location)
11. ✅ Footer name
12. ✅ Footer links

---

**💡 Tip:** `index.html` file खोलें, `Ctrl+F` से "Your Name" search करें और सभी जगह update करें!
