# 🌐 Portfolio को Online/URL पर कैसे Deploy करें?

## ⚡ सबसे आसान: Netlify (2 मिनट - FREE)

### Steps:
1. **https://www.netlify.com** पर जाएं
2. **Sign up** करें (Google/GitHub account से - FREE)
3. **"Add new site"** > **"Deploy manually"** click करें
4. **Portfolio folder** को drag & drop करें
   - Folder: `C:\Users\krish\OneDrive\Desktop\my portfolio`
5. **2-3 सेकंड** में deploy हो जाएगा!
6. आपको **URL मिलेगा** जैसे: `amazing-portfolio-123.netlify.app`
7. यह URL **कहीं से भी** काम करेगा - mobile, laptop, कहीं से भी!

### ✅ Advantages:
- ✅ 100% FREE
- 2 मिनट में ready
- Professional URL
- Mobile पर perfect
- LinkedIn/CV में share कर सकते हैं
- Custom domain भी add कर सकते हैं (बाद में)

## 🔄 Alternative: GitHub Pages (FREE)

### Steps:
1. **https://github.com** पर account बनाएं
2. **New repository** बनाएं (जैसे: "my-portfolio")
3. सभी files upload करें:
   - index.html
   - styles.css
   - script.js
   - README.md
4. **Settings** > **Pages** में जाएं
5. **Source**: "main branch" चुनें
6. **Save** करें
7. 2-3 मिनट बाद site live होगी:
   - URL: `yourusername.github.io/my-portfolio`

---

## 🚀 Vercel (FREE - Fast)

### Steps:
1. **https://vercel.com** पर जाएं
2. **Sign up** करें (GitHub से)
3. **"Add New Project"** click करें
4. Portfolio folder upload करें
5. **Deploy** click करें
6. Instant URL मिलेगा!
